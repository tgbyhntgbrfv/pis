# **ВВЕДЕНИЕ** 

Информационная система «Автошкола» предназначена для создания временных окон для занятий и экзаменов путем занесения в соответствующую базу данных и бронирования занятий курсантами. Данная система оптимизирует процесс работы с базами данных и позволяет исключить прямое взаимодействие администратора и клиентов (больше времени на другие задачи). 

Информационная система предоставляет функциональные возможности двум основным категориям пользователей: 

1. Администратор — управляет учебным процессом: заносит в базу данных доступное время занятий (формирует расписание), управляет учётными записями курсантов. Регистрация проводится оффлайн в формате выдачи пары логин/пароль клиенту. 

2. Курсант — обучающийся, взаимодействующий через веб-интерфейс: просматривает доступное время для записи, выбирает удобные слоты занятий, отслеживает своё расписание. 

Разрабатываемая система позволяет автоматизировать типовые операции по составлению расписания (добавить временное окно, выбрать тип занятия), снизить количество ошибок при записи на занятия (например, накладки по времени или запись к занятому инструктору), повысить скорость обслуживания курсантов и обеспечить прозрачный контроль учебного процесса.

Рисунок 1.3 – окно «Курсанты» 

**Название прецедента** : удалить курсанта 

Предусловия: пользователь авторизован как «Администратор», открыто окно «Курсанты» (рис. 1.3), введено ID курсанта. 

Основной сценарий: 

1. Администратор нажимает кнопку «Удалить». 

2. Система запрашивает подтверждение удаления. 

3. Администратор подтверждает действие. 

Постусловие: запись курсанта удалена из базы данных, его учётная запись заблокирована, все его будущие бронирования отменены.

Альтернативный сценарий (отказ от подтверждения): администратор нажимает «Отмена» в диалоговом окне. Удаление не выполняется. 

Альтернативный сценарий (у курсанта есть активные бронирования): система выводит предупреждение «У курсанта есть активные записи на занятия. Удаление приведёт к их отмене» и требует повторного подтверждения. 

**Название прецедента** : создать занятие 

Предусловия: пользователь авторизован как «Администратор», открыто окно «Занятия». 

Основной сценарий: 

1. Администратор нажимает кнопку «Добавить занятие». 

2. Заполняет поля: дата, время начала, время окончания, тип занятия (теория / вождение / экзамен), инструктор, учебный класс или автомобиль, количество мест. 

3. Нажимает кнопку «Сохранить». 

Постусловие: новое временное окно добавлено в расписание и становится доступным курсантам для бронирования. 

Альтернативный сценарий (не все поля заполнены): система выводит сообщение «Заполните все поля». Сохранение отменяется. 

Альтернативный сценарий (конфликт расписания): система выводит сообщение «На выбранное время уже назначено занятие у этого инструктора или в этом классе». Сохранение отменяется.
